# Epinizer — original castle interface

2026-10-24 (Codex). Mode: Operate, native desktop JUCE, fixed 1000 × 640 logical px.
Direction supplied by Roman: black/white, green gradients, a dark abandoned castle
entrance overgrown with greenery. Independent execution, developer MyDarknessDays.

## Composition
One photographic scene fills the window. Header contains product, developer and preset.
Four character tabs sit below. The castle doorway remains visible above five controls.
A single quiet lower surface carries dials, editable percentages and short descriptions.
Echo/Hold/bypass and a real output meter occupy the footer. No separate marketing hero.

## Visual rules
- Off-white #F0F2EC and secondary #B5BFB3 on deep forest/graphite #101510.
- Green #A8E878 to forest #397F50 on active controls; Mix uses a white/grey arc.
- Matte circular faces, soft offset shadows, thin value arcs and legible borderless percentages.
- Character/toggle buttons use quiet filled surfaces; the active character has a short underline.
- No permanent control outlines. Green outlines identify keyboard focus only.
- System fonts requested through JUCE; no downloaded or embedded font files.
- Background Assets/castle-entrance.png is generated for this project from text.
- Original Epinizer paint/layout code. No imported PowerBass/PowerKick interface assets.
- Visible state includes text, indicator and contrast, not colour alone.
- Keyboard focus outlines, editable percentage fields and tooltips remain functional.

## Behaviour and identity
The five visible names reflect implemented parameters: Space, Density, Motion, Width, Mix.
Do not label old DSP with the future macro names. AU component codes, VST3 identity inputs
and bundle ID stay unchanged; displayed developer becomes MyDarknessDays.
