# Epinizer 2.0

Epinizer превращает входной звук в ансамбль с характерной атмосферой. Подходит
для синтезаторов, голоса, гитар и ударных. AU только для macOS, VST3 только для
Windows; общий C++17 DSP и интерфейс JUCE 8.0.12.

В Git находятся исходники, тесты, журнал и скрипты. Каталоги build/third_party/dist
и локальные резервные копии не загружены: JUCE скачивается автоматически при
первой сборке, установочные пакеты создаются в dist. Готовые локальные пакеты
и аудиопримеры доступны в рабочей папке проекта на Mac.

## Что изменилось в звуке

Вместо двух тихих detune-голосов — шесть независимых голосов с разными задержками,
панорамой и дрейфом высоты. Плотность увеличивает число слышимых голосов.
Низкочастотное тело ансамбля остаётся в центре; стереовход в основном тракте
сохраняется. Огибающая входа приглушает пространственный фон во время нот и
открывает его в паузах. Это динамическая обработка по уровню, не спектральное
разделение сигнала и не автоматическое распознавание инструмента.

| Характер | Реальная обработка |
|---|---|
| Glass | Ансамбль, светлый верхний октавный слой, прозрачные отражения |
| Massive | Нижняя октава, плотный ансамбль, усиленное тело и атака |
| Horroble | Обратные фрагменты, частотная модуляция и тёмное пространство |
| Warm | Более тёмное ленточное эхо, мягкое насыщение и медленный дрейф |

Октавные слои используют оконный сдвиг высоты: возможна зернистость и боковые
частоты, особенно на сложном материале. Это фактура эффекта, не чистый вокальный
гармонизатор. Реверб остаётся одним из слоёв. Обработка не генерирует звук без входа,
за исключением ранее захваченного Hold.

## Быстрый старт на Mac

Проверенный способ без администратора: распакуйте
`dist/Epinizer-2.0.0-macOS.zip`, запустите `Install Epinizer.command`.
Для установки всем пользователям есть `Epinizer-2.0.0-macOS.pkg` (администратор);
его системная установка не проверялась, подробности сборки — VALIDATION.md.
Пользовательская папка: `~/Library/Audio/Plug-Ins/Components`.
Предыдущий пользовательский AU сохраняется в
`~/Library/Application Support/Epinizer/Backups`.

Перезапустите DAW. В Logic: эффекты → **Epinizer Audio → Epinizer**.
Начните с **Glass / Prism ensemble**, затем попробуйте **Massive / Titan**
и **Horroble / Dark ritual**. Для обработки в send-шине поставьте Mix 100%.
Universal AU содержит arm64 и x86_64, минимальная macOS 11.0.

Подпись AU локальная ad-hoc. Developer ID, нотариализация и подпись установщика
не выполнялись. Если macOS блокирует вашу доверенную локальную сборку,
используйте стандартное разрешение открытия в «Конфиденциальность и безопасность».

## Windows

Распакуйте **весь** `Epinizer-2.0.0-Windows-x64.zip` и запустите
`Install-Epinizer.cmd`; подтвердите стандартный запрос UAC.
VST3 устанавливается в `C:\Program Files\Common Files\VST3`.
Предыдущая версия сохраняется в `%LOCALAPPDATA%\Epinizer\Backups`.
После установки пересканируйте VST3 в DAW. Отдельные compiler runtime DLL не нужны.

Пределы проверки именно версии 2.0 описаны в `VALIDATION.md`.
Проверки Wine не означают проверку в настоящей Windows DAW.
`Validate-Epinizer.cmd` запускает пять тестовых программ, пишет
`validation-results.txt`, ограничивает каждый тест 60 секундами.

## Управление

| Макро | Назначение |
|---|---|
| Space | Масштаб атмосферы, затухание и раскрытие пространства в паузах |
| Density | Плотность ансамбля, октавные/характерные слои и насыщение |
| Motion | Разброс detune, дрейф голосов, выразительность движения и Echo |
| Mix | Баланс исходного и обработанного звука; 0% прозрачен |

**Echo** добавляет отражения 135/203 мс. В Warm они становятся более тёмными,
длинными (примерно 190/285 мс) и слегка плавают по времени.
**Hold** удерживает последний обработанный фрагмент как постоянный фон.
После отпускания возвращается текущая обработка. Исходный dry-звук продолжает
проходить согласно Mix. Если включить Hold до поступления звука, удерживается
тишина. Захваченный аудиофрагмент не сохраняется в проекте DAW; состояние кнопки
сохраняется, поэтому после восстановления проекта сначала отпустите Hold,
проиграйте звук и захватите новый фрагмент.

Все восемь параметров, включая характер/Echo/Hold/bypass, доступны автоматизации.
Ручки: перетаскивание, колесо или ввод процентов; двойной щелчок возвращает
начальное значение. Четыре характера переключаются без изменения ручек.
Восемь заводских пресетов меняют характер и макро, включают Echo и отпускают Hold.
Название пресета обозначает отправную точку; редактор не является менеджером
отдельных пользовательских preset-файлов. Настройки сохраняются в проекте DAW.

## Обновление с версии 1

Параметры и их идентификаторы сохранены; старые значения и автоматизация читаются.
Состояния без Hold получают Hold=false; состояния первой версии без Echo — Echo=false.
**Звучание изменится**, поскольку DSP полностью переработан. Для старого звучания
сохранён установщик v1 в `dist/archive/1.0.0`; используйте резервные копии проектов.

## Сравнить звук

`dist/demos-v2/`: синтезатор, ударные и русская речь, синтезированная системным
голосом Milena. Файлы `AB-v1-then-v2.wav`: сначала старая версия, затем новая,
между ними пауза. Файлы выровнены по RMS активного участка, не по LUFS.
Тот же вход и те же макро (.55/.72/.55/.65) в обоих вариантах.
`Hold-capture-sustain-release.wav`: 2 с входа → 3 с удержания → отпускание.
Субъективный результат оцените в вашей музыке; тесты подтверждают работоспособность
и различия обработки, но не заменяют прослушивание в миксе.

## Сборка и проверки

macOS: Command Line Tools, CMake 3.22+; `bash scripts/build-macos.sh`.
Для CMake вне PATH: `CMAKE=/absolute/path/to/cmake bash scripts/build-macos.sh`.
JUCE закреплён на 8.0.12 / `29396c22c93392d6738e021b83196283d6e4d850`.
Если `third_party/JUCE` отсутствует, CMake получает эту версию из GitHub.

`ctest --test-dir build -C Release --output-on-failure` — DSP, параметры/UI,
характеры/Hold и realtime C++ allocation checks. Проверки памяти:

```sh
clang++ -std=c++17 -O2 -fsanitize=address,undefined -I Source tests/DspTests.cpp -o /tmp/epinizer-dsp-tests
/tmp/epinizer-dsp-tests
clang++ -std=c++17 -O2 -fsanitize=address,undefined -I Source tests/CharacterTests.cpp -o /tmp/epinizer-character-tests
/tmp/epinizer-character-tests
```

Windows: Visual Studio 2022 Desktop development with C++, CMake 3.22+;
`powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1`.
Кросс-сборка: `scripts/build-windows-cross.sh`, переменные `EPINIZER_LLVM_ROOT`
и `EPINIZER_WINSDK`, необязательная `EPINIZER_WINE` для moduleinfo.json.
Подробности: `scripts/WINDOWS-BUILD.md`. Старый каталог build-windows-msvc содержит
v1; новая кросс-сборка использует **build-windows-v2-msvc**.
Workflow `.github/workflows/build.yml` подготовлен для ручного запуска; публикация
и cloud CI не выполнялись.

## Технические свойства и ограничения

Mono→mono / stereo→stereo, float32. Dry-путь без отчётной задержки; дополнительные
голоса и атмосфера имеют собственные задержки. Макро/Echo/Hold/bypass сглажены
за 40 мс, характер — 120 мс. На аудиопотоке нет new/delete, блокировок, файлов и UI.
Hold использует конечный цикл 280 мс с перекрытием 35 мс, без бесконечного feedback.
Он сообщается хосту как бесконечный хвост, пока включён; обычный хвост — 12 с.
Стереосвязанная защита уровня действует на обработанный выход. Mix 0 и полный
bypass сохраняют исходный уровень, включая уже перегруженный вход.
Насыщение без oversampling; на высокой Density возможен цифровой характер.
Глубокое гранулярное растяжение и отдельный режим спектрального freeze не реализованы.

Удаление: при закрытой DAW удалите Epinizer.component из выбранной Components
или Epinizer.vst3 из Common Files/VST3. Условия JUCE и зависимостей — THIRD_PARTY.md.
Коммерческая лицензия не приобреталась, публичная публикация не выполнялась.
